5. Перевод по cron:
Задайте секрет для cron в настройках модуля, сохраните и вызывайте из cron ссылку со вкладки "Перевод контента сайта". Подробности:
https://github.com/vhoshko/opencart-translate-expert#cron-translation
Запуск останавливается не позже чем через 15 минут. Ограничение PHP max_execution_time на хостинге и тайм-аут планировщика (например, тайм-аут чтения wget) всё равно действуют, поэтому выберите количество строк, которое успеет выполниться.
