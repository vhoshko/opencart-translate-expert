# Release 05.00.0100

Дата релізу: 23.11.2026

## Нові можливості

- Підтримка OpenCart 4.1
- Новий дизайн адмін-панелі: вкладки «Контент сайту», «Файли каталогу», «Файли адмінки», «Налаштування», «Debug» та «Про модуль»
- Переклад мовних файлів в адмінці: список усіх файлів і редагування перекладених значень
- Сканування та переклад мовних файлів каталогу розширень в OpenCart 4.x
- Cron-переклад полів бази даних
- Налаштування, щоб не завантажувати модуль на вибраних маршрутах адмінки
- Мапа мовних кодів API-клієнта тепер є глобальним налаштуванням
- Кілька значень у фільтрах таблиці, категорії та статусу наявності, а також мультивибір фільтра виробника з лімітом 100 елементів
- Маскування ключа Google API в налаштуваннях з кнопкою показу
- Згортання карток cron, виключених маршрутів і мовних кодів на вкладці «Налаштування»
- Панель підсумку та повернення JSON-даних з AJAX-дій
- POST для removeDataFromDb і resetCache, повідомлення resetCache і JSON-помилки при винятках
- Видалено кнопку Reset біля лічильника символів у шапці адмінки
- Іконка модуля та кольорова частина в назві модуля
- Інформація про криптодонати в README, на вкладці «Про модуль» та в описах для магазинів
- Команда /release для підвищення версії, тегу, збірки та публікації релізу на GitHub

## Виправлення

- Розділення пакетних запитів до Google за кількістю текстів, щоб уникнути помилки «Too many text segments»
- Підрахунок символів, що йдуть до Google, в аналізі та під час перекладу
- Збереження місячного лічильника символів під час збереження налаштувань
- Показ лічильника перекладених символів у шапці адмінки OpenCart 1.5
- Додано файли шрифтів Font Awesome 4.4.0 до пакета OpenCart 1.5
- Читання ключів мовних файлів через PHP-токени, щоб аналіз знаходив значення з PHP-кодом
- Узгодження мовних ключів адмінки модуля та перенесення жорстко заданих текстів інтерфейсу до мовних файлів
- Друга мова вибирається мовою «до» за замовчуванням, якщо немає значення в сесії
- Усунено помилку JavaScript в адмінці, коли id textarea пакетного редактора не має числа
- Усунено помилку JavaScript в адмінці, коли в URL немає параметра route
- Приведення типів значень заголовка OCMOD, щоб незбережені налаштування не ламали JavaScript адмінки
- Встановлення релізної версії з _version.txt у docker/install-module.sh

## Інші зміни

- Файли бібліотек перенесено в translate_expert/ і перейменовано з префіксом translate_expert_
- Перезаписи для версій OpenCart перенесено з build.sh в код модуля
- Додано Docker-магазини для тестів OpenCart 1.5, 2.0, 2.1, 2.2, 2.3, 3.0 і 4.0 та мову uk-ua
- Додано конфігурацію робочого процесу Claude Code і перевірку синтаксису JavaScript
- Інструкції для агентів переписано простою технічною англійською ASD-STE100
- Моделі робочого процесу /do: план Opus, реалізація Sonnet, рев'ю Opus
- Додано файли описів для магазинів англійською та українською, розширено кроки отримання ключа Google Cloud Translation API
- Додано PoC нового дизайну адмін-панелі та формати JSON
- Оновлено README
- Оновлено «Про модуль»: посилання на GitHub, видалено згадки translator.codeguild.com.ua
