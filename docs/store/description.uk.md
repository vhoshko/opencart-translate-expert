# Масовий автоматичний переклад текстів, товарів, категорій, статей тощо з Google translate API - елітий модуль

Translate Expert — це модуль для адмінки OpenCart. Він використовує Google Cloud Translation API, щоб перекласти вміст Вашого магазину на будь-яку мову, яку підтримує Google. Модуль знаходить тексти без перекладу, показує кількість символів у них і перекладає їх масово з адмінки або через cron.

## Основні можливості

- Масовий переклад вмісту бази даних: товари, категорії, статті та інші багатомовні таблиці.
- Аналіз неперекладених і однакових текстів перед перекладом, з кількістю символів.
- Переклад і ручне редагування файлів локалізації (магазин і адмінка).
- Кнопка «Перекласти» біля кожного багатомовного поля в адмінці.
- Переклад за розкладом через посилання для cron.
- Лічильник використаних символів зі щомісячним скиданням і оцінкою вартості.
- Працює з OpenCart від 1.5 до 4.1.

## Переклад контенту сайту

- Виберіть мову оригіналу та мову перекладу. Кнопка міняє їх місцями.
- Виберіть, що перекладати:
  - `both`: порожні значення та значення, що збігаються з оригіналом.
  - `only_empty`: лише порожні значення.
  - `same_value`: лише значення, що збігаються з оригіналом.
- Виберіть одну таблицю, кілька таблиць або всі таблиці. Кнопки «Вибрати всі» та «Очистити вибір» допомагають із довгими списками. В аналізі є лише таблиці з колонкою `language_id` і текстовими колонками.
- Глибокий аналіз (увімкнений за замовчуванням) показує символи за кожною таблицею та кожною колонкою.
- «Докладно» показує перші 100 значень колонки: текст оригіналу та текст перекладу.
- Перекладайте одну таблицю або натисніть «Перекласти все». Кнопка «Зупинити» завершує роботу, що виконується.
- Фільтри товарів у блоці «Додаткові фільтри»: лише активні товари, товари з кількістю більше 0, категорія, статус наявності та виробник.
- Модуль запам'ятовує поля, у яких переклад збігається з оригіналом. Він більше не пропонує ці поля. Пам'ять можна скинути на вкладці «Відлагодження».
- Тексти з HTML-тегами надсилаються в Google як HTML, тому теги зберігають структуру.
- Заповнювачі, як-от `%d` і `%s`, залишаються правильними після перекладу.
- Якщо Google повертає порожній текст, модуль залишає текст оригіналу.
- «Видалити переклад» очищає перекладені значення однієї цільової мови для вибраних таблиць і фільтрів. Зробіть резервну копію перед використанням.

## Файли локалізації

- Дві вкладки: «Файли магазину» і «Файли адмінки».
- Аналіз показує, у яких файлах є відсутні або частково перекладені значення, і список ключів кожного файлу.
- Перекладайте один файл, редагуйте його вручну та зберігайте, або натисніть «Перекласти все». Кнопка «Зупинити» завершує роботу, що виконується.
- В OpenCart 4.x модуль також сканує папки мов розширень.
- PHP-вирази у значеннях залишаються без змін.

## Кнопка «Перекласти» в адмінці

- Кнопка «Перекласти» з'являється біля кожного багатомовного поля в адмінці.
- Вона працює зі звичайними полями, текстовими областями та редакторами Summernote, CKEditor і GrapesJS.
- Вона також працює зі сторінками Simple, пакетного редактора та Handy Product Manager.
- Налаштування «Виключені маршрути» дає змогу вимкнути модуль на вказаних сторінках. Один маршрут на рядок, `*` в кінці означає префікс.

## Переклад за розкладом (cron)

- Вкажіть секрет (від 16 до 128 символів, кнопка «Згенерувати» створює його) і кількість рядків за один запуск.
- Скопіюйте посилання для cron з вкладки «Контент сайту» і викликайте його з cron, наприклад через `wget`.
- Посилання для cron використовує таблиці, режим і фільтри, які Ви вибрали на вкладці «Контент сайту».
- Кожен виклик перекладає одну порцію та повертає JSON з полями `done`, `rows`, `chars`, `table` і `error`.
- Викликайте посилання повторно, доки `done` не стане `true`.
- Помилки: `forbidden`, `disabled`, `bad_params`, `busy` і `translate_failed`.
- Одночасно працює лише один запуск. Запуск зупиняється не пізніше ніж через 15 хвилин.
- Посилання не працює, коли магазин у режимі обслуговування.

## Налаштування та інструменти

- Підключення: введіть ключ Google API. Кнопки «Показати ключ» і «Сховати ключ» допомагають перевірити його.
- Використання символів: модуль рахує символи, які надсилає до Google. Щомісячне скидання — за вибором, а кнопка «Скинути» на сторінці модуля обнуляє лічильник вручну. Окрема опція показує лічильник у шапці всіх сторінок адмінки.
- Оцінка вартості: лічильник враховує 500 000 безкоштовних символів на місяць і $20 за кожні 1 000 000 символів понад цей ліміт. Це фіксовані значення модуля. Перевірте актуальний прайс Google Cloud Translation.
- Коди мов: зіставте коди мов Вашого магазину з кодами Google. Типові значення: `ua` на `uk`, `rs` на `sr`, `ge` на `ka`, `cz` на `cs`.
- Пробний переклад: тестове поле для кожної мови магазину.
- Вкладка «Відлагодження»: версії модуля, OpenCart і PHP, скидання кешу перекладів, режим відлагодження та журнал (перегляд, завантаження, очищення).
- Інтерфейс модуля: англійська, російська та українська мови.

## Ключ Google Cloud Translation API

1. Увійдіть до свого облікового запису Google і відкрийте консоль Google Cloud: https://console.cloud.google.com/
2. Створіть проєкт або виберіть наявний.
3. Увімкніть Cloud Translation API для проєкту.
4. Налаштуйте виставлення рахунків, якщо Google цього вимагає. Google може надавати новим обліковим записам безкоштовний пробний кредит. Перевірте актуальну пропозицію.
5. Створіть ключ API в розділі облікових даних.
6. Введіть ключ у налаштуваннях модуля, в блоці «Підключення».

Ціни та правила Google можуть змінюватися. Перевіряйте їх у своєму обліковому записі Google Cloud.

## Сумісність

- OpenCart 1.5, 2.0, 2.1, 2.2, 2.3, 3.0, 4.0.2.x і 4.1.0.x.
- PHP 5.6, 7.0, 7.1 і вище, та 8.x. OpenCart 4.0 потребує PHP 8.0 або вище. OpenCart 4.1 потребує PHP 8.1 або вище.
- OpenCart 1.5 потребує vQmod. Інші версії використовують OCMOD.
- Пакет містить окремий файл встановлення для кожної версії OpenCart.
